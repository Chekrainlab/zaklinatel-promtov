# Заклинатель промтов

Браузерная аркада для Яндекс Игр. Маг Кодомаг побеждает баг-монстров точными промтами для ИИ, а игрок между делом учится вайбкодингу.

## Как запустить

Откройте `index.html` в браузере. Сборка не нужна, всё на чистом HTML, CSS и JavaScript.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `js/levels.js` | Сюжет, арки, уровни, диалоги, подсказки |
| `js/grader.js` | Проверка промта по пяти частям: суть, контекст, результат, ограничения, формат |
| `js/platform.js` | Яндекс Игры SDK: реклама и облачные сохранения. Вне Яндекса работает заглушка |
| `js/game.js` | Экраны: титул, карта мира, диалоги, бой |
| `tests/` | Тесты проверки промтов: `node --test tests/*.test.js` |

Новый уровень добавляется одним объектом в `js/levels.js`. Тест проверяет, что пример-подсказка каждого уровня побеждает с одного удара.

## Для Яндекс Игр

Загрузите в консоль разработчика архив с `index.html`, `css/` и `js/`. SDK подключается сам, когда игра открыта на домене Яндекса.
