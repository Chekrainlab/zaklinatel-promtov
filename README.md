# Кодолесье

Браузерное 2D-приключение для Яндекс Игр. Повелитель Багов украл Духа Кода, доброго ИИ, который исполнял желания жителей. Игрок ходит по миру, помогает жителям и собирает просьбы к Духу из карточек. Точная просьба меняет мир (появляется мост, загораются факелы), неточная приводит к смешной ерунде. Так игрок учится главному в вайбкодинге: говорить точно, ставить ограничения и проверять результат.

Главы:
1. **Кодолесье**: что, где и каким; ограничения; просить объяснить и проверять.
2. **Болото тормозов**: показывать пример; делить большую задачу на шаги; точно говорить, что исправить.
3. **Башня галлюцинаций**: давать ИИ сведения; разрешать «не знаю» и вопросы; просить источник и проверять факты.
4. **Кодоград**: роль; формат ответа; для кого результат.
5. **Цитадель Повелителя** (финал): не давать ИИ пароли и личные данные; сохранять рабочую версию; итоговый промт из всех правил.

Пройденные уроки собираются в «Шпаргалку вайбкодера» на главном экране.

## Как запустить

Откройте `index.html` в браузере. Сборка не нужна, всё на чистом HTML, CSS и JavaScript.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `js/quests.js` | Главы, сюжет, квесты, карточки и что меняется в мире после каждого квеста |
| `js/world.js` | Карты глав, их оформление и векторная отрисовка мира и персонажей |
| `js/game.js` | Движение, диалоги, сборка промта, сохранения |
| `js/audio.js` | Музыка глав и звуки, синтезированные через Web Audio. Пауза при скрытой вкладке и во время рекламы |
| `js/platform.js` | Яндекс Игры SDK: реклама и облачные сохранения. Вне Яндекса работает заглушка |
| `tests/` | Проверки квестов и карты: `node --test tests/*.test.js` |

Новая глава — это карта в `MAPS` (`js/world.js`) и запись в `CHAPTERS` (`js/quests.js`) с тем же порядковым номером. Новый квест добавляется объектом в главу и жителем на её карте. Тесты проверяют, что в каждом слоте ровно одна верная карточка и что до каждого жителя можно дойти после предыдущего квеста.

## Для Яндекс Игр

1. Соберите архив: `python3 tools/build.py`. Получится `dist/kodolesie-yandex.zip` (index.html в корне, шрифты внутри, загрузчик `/sdk.js` подключён).
2. В консоли разработчика создайте таблицу лидеров с техническим именем `stars` (в неё попадают звёзды игрока).
3. Включите в черновике облачные сохранения: игра пишет прогресс через `player.setData()`.
4. Иконка, обложка и скриншоты лежат в `promo/`: `icon.png` 512×512, `cover.png` 800×470, по 4 скриншота для компьютера (1920×1080) и 3 для телефона (1080×1920).

Что уже сделано по требованиям Яндекса: `LoadingAPI.ready()`, разметка `GameplayAPI.start/stop`, пауза звука при рекламе, свёрнутой вкладке и потере фокуса, события `game_api_pause/resume`, управление WASD при любой раскладке, без выделения текста и контекстного меню, игра целиком помещается в окно без прокрутки, кнопка подсказки прямо говорит, что это реклама, вход через Яндекс только по кнопке.
